# 🔐 Sistema de Cadastro e Login em Python

Sistema simples de **cadastro e autenticação de usuários desenvolvido em Python**, criado como projeto de estudo e treinamento de lógica de programação.
Além disso, o projeto também foi utilizado para explorar conceitos de programação procedural e estruturada.

O projeto foi desenvolvido utilizando conhecimentos básicos de Python, com o objetivo de praticar sintaxe, estruturas condicionais, estruturas de repetição, manipulação de strings e construção de scripts.

> **Status:** 🚧 Em desenvolvimento  
> **Objetivo:** Estudo e prática de programação em Python

---

## 📌 Sobre o projeto

O sistema simula um processo básico de cadastro e login.

Durante a execução, o usuário pode:

- Criar um nome de usuário;
- Informar um e-mail para login;
- Criar uma senha;
- Validar se a senha possui pelo menos 8 caracteres;
- Visualizar as credenciais cadastradas;
- Realizar login utilizando as credenciais informadas;
- Tentar novamente caso as credenciais estejam incorretas.

O projeto foi desenvolvido individualmente como exercício de **raciocínio lógico, memória e aplicação prática dos conhecimentos básicos de Python**.

---

## ⚙️ Funcionalidades

### Cadastro

- Solicita o nome do usuário;
- Solicita um e-mail para login;
- Solicita a criação de uma senha;
- Verifica o tamanho mínimo da senha.

### Autenticação

- Solicita o e-mail cadastrado;
- Solicita a senha;
- Compara as informações fornecidas com as credenciais cadastradas;
- Informa se o login foi realizado com sucesso;
- Permite novas tentativas em caso de erro.

## ▶️ Como executar

### 1. Instale o Python

Baixe e instale o Python em sua máquina.

### 2. Clone o repositório

```bash
git clone https://github.com/GGbrl/login-system-python.git
```

### 3. Entre na pasta do projeto

```bash
cd login-system-python
```

### 4. Execute o programa

```bash
python main.py
```

Também é possível abrir o projeto diretamente pelo **PyCharm** e executar o arquivo Python pelo botão de execução.
